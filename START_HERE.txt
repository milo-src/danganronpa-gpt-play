DANGANRONPA GPT PLAY — БЫСТРЫЙ ЗАПУСК

1. СКАЧАЙ ПРОЕКТ
Скачай весь репозиторий ZIP-архивом и распакуй или используй git clone.
Не загружай только отдельный manifest: рядом необходимы src и public/assets.
Node, Python, npm install, сборка и API-ключи для игры НЕ нужны.
manifest.json в корне уже готов к установке из этой папки.

2. УСТАНОВИ РАСШИРЕНИЕ
Chrome: открой chrome://extensions, включи «Режим разработчика», нажми
«Загрузить распакованное расширение» и выбери папку с manifest.json.
Edge: аналогично через edge://extensions.
Firefox: открой about:debugging#/runtime/this-firefox, нажми «Загрузить
временное дополнение» и выбери manifest.json. Нужен Firefox 140 или новее.
Временная установка Firefox действует до перезапуска браузера; после него
загрузи дополнение снова. Постоянная установка требует подписанной сборки;
этот репозиторий пока её не содержит.
После установки ОБНОВИ уже открытые вкладки ChatGPT.

3. СОЗДАЙ ИГРОВОЙ ПРОЕКТ В ВЕБ-CHATGPT
На chatgpt.com создай отдельный проект для игры.
Содержимое instructions/CHATGPT_PROJECT_INSTRUCTIONS.txt целиком скопируй в
инструкции проекта. Это один самодостаточный файл короче 8000 символов:
внутри уже есть правила, формат DGP, все персонажи и компактный каталог фонов.
Прикреплять ASSET_CATALOG.txt или другие файлы для запуска больше не нужно.
PROJECT_DESCRIPTION.txt содержит описание проекта; его можно использовать
для представления игры или прикрепить дополнительно.
Сами сотни мегабайт изображений загружать в ChatGPT не нужно.

4. ИГРАЙ
Открой новый диалог ВНУТРИ этого проекта. Нажми RONPA · ВЫКЛ внизу страницы
или открой меню расширения и нажми «Включить игру».
Напиши: «Начни новую игру по инструкциям проекта. Формат ответа DGP».
Вначале выбери часть, героя и режим спойлеров. Затем играй своими сообщениями.
Каждая завершённая строка команды появляется в сцене ещё во время ответа.
«Далее» сначала допечатывает реплику, затем переходит к следующей.
Пиши действие в настоящем поле ChatGPT ПОД сценой. Отправляй обычной стрелкой
сайта или Enter; Shift+Enter добавляет строку. Расширение оставляет это поле
открытым и не перехватывает его клавиши. Второго игрового поля больше нет.
Кнопки выбора, «Начать игру» и «Предъявить улику» только подготавливают черновик.
Ты можешь изменить его и сам отправить стрелкой сайта. Существующий другой
черновик не заменяется. Если вставка варианта недоступна, можно написать
действие напрямую в открытом поле ChatGPT, не закрывая сцену.
«Открыть чат» показывает обычную страницу, сохраняя режим; новый игровой ответ
снова откроет сцену. «Выкл» прекращает наблюдение за сообщениями.
При создании чата запуск переносится по совпадению проекта и стартового запроса
в течение 10 минут, даже если пришлось вставить запрос вручную. Если уже видишь
блок DGP, но снизу написано «RONPA · ВЫКЛ», нажми эту кнопку: готовый ответ
будет прочитан без повторной отправки сообщения.
Space / стрелка вправо работают, когда фокус на сцене; Esc сворачивает её.

5. ПРОВЕРКА БЕЗ CHATGPT
Открой public/demo.html в браузере (обычный файл, двойной клик).
Это тестовый диалог с теми же сценой, парсером и адаптером. Он не подключён
к модели. Кнопки позволяют проверить потоковый ответ, суд, улики и сбой формата.
public/backgrounds.html — отдельная галерея имеющихся локаций.

ЕСЛИ СЦЕНА НЕ ПОЯВИЛАСЬ
- Убедись, что ты на chatgpt.com в обычном диалоге, расширение включено,
  вкладка обновлена после его установки, а не открыта внутри приложения Codex.
- В ответе должны быть строки DGP|{"type":"scene",...} и DGP|{"type":"say",...}.
  Попроси ChatGPT переформатировать последний ответ по инструкциям проекта.
- Если картинок нет, проверь, что public/assets скачан целиком и остался
  рядом с manifest. Не перемещай отдельные части установленного расширения.
- При обновлении кода нажми перезагрузку расширения в браузере, затем обнови чат.
  В шапке игры должна быть версия 0.3.0. В Firefox загрузи manifest.json именно
  из актуальной папки проекта; для этой установки это D:\Projects\danganronpa-gpt-play.
- После «Перезагрузить» в about:debugging обязательно обнови саму страницу
  ChatGPT через Ctrl+Shift+R: перезагрузка дополнения не заменяет обновление чата.
- Если снизу «RONPA · ОТКРЫТЬ», нажми её: уже полученные ответы будут перечитаны.
- «Настройки» → «Перечитать сообщения» повторно читает текущую страницу.
  Там же видны версия, число ответов, команд, ошибок и наличие поля ввода.
- Если ChatGPT ответил обычным текстом или сломанным JSON, в игре появится
  «Исправить формат ответа»: она просит переоформить ответ без перезапуска сюжета.
- При лимите ChatGPT, требовании входа или ошибке сети открой обычный чат.
  Расширение не повторяет отправку автоматически: это предотвращает дубли ходов.
- Возобновление опирается на сообщения, которые сайт загрузил на страницу.
  Если старый контекст не виден, попроси модель прислать текущий полный scene
  с найденными уликами и следующую реплику. Тайные сведения в scene не нужны.

ДАННЫЕ
Расширение не использует внешнюю аналитику и не делает сетевых запросов к API.
Оно читает игровые команды только из ответов на открытой странице и загружает
изображения из своей папки. Локально сохраняет ID чата, переключатель, хеш позиции
чтения и настройки, а при запуске — временный хеш стартового запроса для переноса
режима в созданный чат. Полную переписку не сохраняет и никуда не пересылает.
Расширение само не нажимает отправку. Сообщение отправляет игрок настоящей
кнопкой сайта или Enter. API и фоновых запросов к модели нет.

ДЛЯ РАЗРАБОТКИ (не требуется игроку)
node scripts/build-runtime.cjs — обновить каталоги и единые инструкции после
добавления ресурсов. Генератор проверяет бюджет текста с учётом переносов Windows.
node --test tests/protocol.test.cjs tests/app.test.cjs — проверить парсер,
очередь, переключение чатов и безопасность данных.
node scripts/check-extension.cjs — проверить manifest, пути и синтаксис.
Если установлен npm, доступны также npm test и npm run check.
Исходные изображения и документы в .md не нужны для запуска; .md и docs
игнорируются Git по настройкам проекта.
