# Danganronpa GPT Play

Браузерное расширение, которое превращает чат с ChatGPT в визуальную новеллу в духе Danganronpa: персонажи со спрайтами, диалоговое окно, локации, музыка, эффекты и режим классного суда.

Сейчас здесь подготовлена структура проекта и место для ресурсов. Работающего расширения, сборки и подключения к ChatGPT пока нет.

## Структура

```text
danganronpa-gpt-play/
├── public/                         # Готовые ресурсы; при сборке копируются в корень расширения
│   ├── icons/                      # Иконки самого расширения
│   └── assets/
│       ├── characters/
│       │   ├── _template/          # Шаблон папки персонажа и пример описания
│       │   ├── dr1/                # Trigger Happy Havoc
│       │   ├── dr2/                # Goodbye Despair
│       │   ├── drv3/               # Killing Harmony
│       │   └── custom/             # Собственные персонажи
│       ├── backgrounds/           # Локации и варианты освещения
│       ├── audio/
│       │   ├── music/              # Фоновая музыка
│       │   ├── sfx/                # Звуки интерфейса и событий
│       │   └── voices/             # Короткие голосовые реплики по персонажам
│       ├── ui/                    # Рамки диалогов, кнопки, значки, курсоры
│       ├── effects/               # Оверлеи и изображения визуальных эффектов
│       └── fonts/                 # Шрифты интерфейса
├── src/
│   ├── extension/                 # Будущие manifest и точки входа расширения
│   │   ├── background/            # События расширения и обмен сообщениями
│   │   ├── content/               # Подключение игрового интерфейса к странице
│   │   └── settings/              # Настройки: громкость, скорость текста, оформление
│   ├── adapters/
│   │   └── chatgpt/               # Чтение сообщений и отслеживание изменений страницы
│   ├── game/
│   │   ├── dialogue/              # Очередь реплик, печать текста, история
│   │   ├── scene/                 # Персонажи, позиции, фон, переходы и звук
│   │   └── trial/                 # Режим суда, улики, возражения
│   ├── ui/
│   │   ├── components/            # Диалоговое окно, сцена, меню, панель улик
│   │   └── styles/                # Стили и темы игрового интерфейса
│   └── data/                      # Каталоги ресурсов, доступных игре
├── source-assets/                 # Оригиналы, PSD, нарезка и промежуточные экспорты
└── docs/
    ├── assets.md                  # Как заранее раскладывать спрайты и другие ресурсы
    └── architecture.md            # Границы модулей и поток данных
```

## Куда положить спрайты прямо сейчас

Например, для Макото:

```text
public/assets/characters/dr1/makoto-naegi/
├── character.json
├── sprites/
│   ├── neutral.png
│   ├── happy.png
│   ├── angry.png
│   ├── surprised.png
│   └── thinking.png
└── portraits/
    └── default.png
```

Скопируй `public/assets/characters/_template/` в папку нужной игры, назови копию по персонажу и складывай изображения в `sprites/`. Файл `character.example.json` можно позже переименовать в `character.json` и заполнить по реальным файлам. Пустые `.gitkeep` в заполненных папках можно удалить.

Спрайты можно запасать заранее: пока персонаж не добавлен в `src/data/characters.json`, его папка считается подготовленным набором, а не доступным персонажем игры. Сам загрузчик будет реализован позже.

Подробности: [правила ресурсов](docs/assets.md) и [архитектура](docs/architecture.md).
