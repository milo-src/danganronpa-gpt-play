# Исходные ресурсы

Здесь можно хранить оригиналы изображений, PSD, архивы спрайтов, материалы для нарезки и промежуточные экспорты.

Готовые изображения с прозрачностью переноси в `public/assets/characters/`, фоны — в `public/assets/backgrounds/`, звук — в `public/assets/audio/`.

Эта папка предназначена для подготовки материалов и не должна включаться в сборку расширения. Пока сборщик не настроен, это договорённость о структуре, а не автоматическое правило.

Файлы в этой папке не исключены из Git автоматически: перед добавлением больших исходников стоит отдельно выбрать способ их хранения.
